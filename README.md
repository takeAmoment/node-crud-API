# node-crud-API

## Instruction:

1. Please clone this repo with [`git clone url`];
2. Switch branch to **develop**;
3. Install all dependencies [`npm install`];
4. For running dev mode use [`npm run start:dev`] after that you can check API with Postman;
5. For running production mode [`npm run start:prod`];
6. For running load balancer [`npm run start:multi`];
7. To check tests run [`npm test`]
